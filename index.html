FixAgent (01)

An AI agent that takes a bug report or GitHub issue, explores the code, runs the tests, edits the source and hands back a patch or pull request.

2026, personal project
  • A fix only counts if the tests fail before the agent runs and pass after.
  • Agent loop, tools and LLM client in plain Python, talking to any OpenAI-style tool-calling endpoint.
  • Safety rules: works on a copy, test files are read-only, commands come from an allowlist with a timeout.
  • A fast code-search CLI in Rust and a React/TypeScript dashboard.
  • 68 offline tests run in GitHub Actions. Not yet run with a real model or on a public benchmark.
Python, LLM agents, React, TypeScript, RustView on GitHub ↗

AutoSPECTRA (02)

Deep learning to detect DoS, fuzzing, gear and RPM spoofing attacks on a vehicle CAN bus, with automated incident reports.

2026, MSc group project
  • I designed and own the evaluation harness.
  • Time-ordered train/test splits with automated leakage checks, because neighbouring CAN frames look alike.
  • Per-class precision, recall, F1, ROC-AUC, false-positive rate and detection latency.
  • Baseline, CNN and sequence models compared on identical splits, with window-size ablations.
Python, deep learning, CAN busView on GitHub ↗
